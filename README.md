# PixelConvert

Browser-based tools for converting, cropping, resizing, rotating, flipping, and compressing JPG, PNG, and WEBP images. Image bytes stay in the browser.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

Set `NEXT_PUBLIC_SITE_URL` to the public origin when you deploy so canonical URLs, Open Graph links, and the sitemap match the live site.
